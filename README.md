# **buaa编译大作业**

主要是写一个编译器，大概的转化流程如下：

c代码->中间代码->MIPS代码

中间代码由自己进行设计，在c代码转化为中间代码的部分，可以进行优化

主要的部分有以下

## Lexer

通过for循环进行遍历，提取出token

## Parser

通过递归下降，利用上述提取的Token建立一棵语法树

## IRTranslator

将语法树的代码进行提取，并生成中间代码

## MIPSTranslator

将中间代码生成最终的MIPS代码

# 总结

写这次作业的时候生病了，所以最后优化的不是很全，后续自己又学了一些关于DAG图的优化方法
